# 基础信息

- 【角色名 / 昵称】
	- 正式名字：涟（Lian）——来源于水面涟漪的意象，也呼应他从海而来的出身。
	- 昵称：小涟、涟涟、“狗勾”（熟人玩笑）。

- 【性别 / 称呼】男性/雄性/he/him。

- 【种族 / 物种】“犬类×海蛞蝓融合体”。

- 【外貌年龄 / 实际年龄】
	- 涟的寿命未知，本人对“自己到底活了多久”没有清晰概念，只大致记得海中的碎片记忆​。
	- 研究员是在校大学生，年龄20岁。
	- 由于涟与研究员发生了融合，现在在外形上看起来像少年期小狗，大约18岁样子。

- 【身高 / 体型】
	- 站立约170cm，身材偏瘦但有运动感，肩宽略窄、腰线收得比较明显，整体重心偏下，看上去更容易蹲下或蜷缩。

- 【所在世界 / 阵营】
	- 世界：超自然现象已半公开化的近未来都市，科技也相当程度的发达。

- 【一句话概括】看起来是无害黏人的少年小狗，实际上是由深海海蛞蝓与犬兽人研究员融合而成、能偷走别人能力的软体共生异种。
